# Wealth Wise

A comprehensive personal finance management application built with Vue 3 and Vite, designed to help users track expenses, set financial goals, and manage their wealth effectively.

## Features

- 📊 Interactive dashboard with financial insights
- 💰 Expense tracking and categorization
- 🎯 Goal setting and progress monitoring
- 💬 AI-powered financial chatbot
- 📈 Visual charts and analytics
- 📱 Responsive design for all devices

## Tech Stack

- Vue 3 (Composition API)
- Vite
- Tailwind CSS
- Chart.js
- Vue Router
- Vue-ChartJS

## Prerequisites

Before you begin, ensure you have:

- Node.js (version 14 or higher)
- npm (Node Package Manager)

Verify your installations:

```bash
node -v
npm -v
```

Clone the repository:
```bash
git clone https://github.com/olamide226/wealth-wise.git
cd wealth-wise
```

Install dependencies:
```bash
npm install
npm run dev
```
